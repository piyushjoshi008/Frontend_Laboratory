# Piyush Joshi: Personal Portfolio

A minimal personal portfolio built with plain HTML, CSS and JavaScript (no frameworks).

## Files
- `index.html`: structure and content (Home, About, Skills, Projects, Journey, Contact)
- `style.css`: layout, dark theme colours (CSS variables) and responsive layout
- `script.js`: the two interactive features

## Feature : Developer Console
- Commands live in a JavaScript **object** (`commands`).
- A `submit` **event listener** reads the typed text and passes it to `runCommand()`.
- `if / else if` **conditions** check for `clear`, a known command, or an unknown one.
- **DOM manipulation**: `createElement` and `appendChild` add each new line to the page.
